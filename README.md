## Project Overview

An interactive Power BI dashboard designed to monitor collections performance in a lending operations environment. This independent portfolio project explores how operational data can be transformed into actionable insights for reporting and decision-making.

The project is inspired by the responsibilities of an MIS Analyst role, including collections reporting, KPI tracking, and performance monitoring.

## Dashboard Highlights

- **Allocated vs. Collected Amount:** Compare assigned amounts with actual collections.
- **Collection Rate:** Measure collected amounts as a proportion of allocated amounts.
- **Account Volume:** Track the number of allocated accounts.
- **DPD Bucket Analysis:** Compare collection performance across overdue buckets.
- **Promise-to-Pay (PTP) Analysis:** Monitor kept and broken payment promises, alongside accounts with no recorded promise.
- **Collection Trend:** Explore collection amounts across allocation dates.

## Tools & Skills

- Power BI
- DAX measures
- Data modelling and visualisation
- KPI development and reporting
- Excel-based data preparation

## Dataset

The dashboard uses a small, structured dataset containing 72 simulated account records across fictional clients, collection agents, team leads, and DPD buckets.

**Note:** All data is synthetic and created for educational and portfolio purposes. It does not represent actual customer records or internal data from Pallav Technologies.

## Key Objective

To demonstrate how a well-structured MIS dashboard can consolidate collection metrics into a single view, helping operations teams monitor performance, identify potential gaps, and support data-informed decisions.
